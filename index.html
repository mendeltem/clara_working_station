Das System dahinter

Clara ist ein lokales Modell auf einer einzelnen Workstation, ohne Netzzugang. Werkzeuge, Messungen und Betriebsregeln stehen getrennt in local_models — darunter das modellunabhängige Gerüst, das beschreibt, was einen Agenten fertig werden lässt.

Was hier nicht liegt. Patientendaten und Ergebnisse auf eigenen Kohorten bleiben auf der Maschine. Veröffentlicht wird nur, was auf öffentlichen Datensätzen gerechnet wurde — der QC oben läuft auf der WMH Segmentation Challenge (Utrecht, Singapore, Amsterdam). Vor jedem Push geprüft: jeder Datensatz braucht eine ausdrückliche Freigabe.

Patient data and results on in-house cohorts stay on the machine. Only work on public datasets is published here.
