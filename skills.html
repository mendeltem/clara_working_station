Skills

Clara Working Station

A skill is a folder with one instruction file. The agent always has the name and description of every skill in its prompt and reads the body only when a task calls for it, so a skill costs little until it is used. The Agent Skills format allows a description of at most 1,024 characters and recommends a body under 500 lines.

Click a bar to filter, click a point or a name to see one skill. Counted on 24 November 2026 on the workstation.
