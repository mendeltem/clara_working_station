Limits and data rules

Clara Working Station

Limits

  • The method comparison uses 20 of the 110 public test cases, a QC sample, not the full test set. The 2017 winner line is on all 110 cases.
  • Clara's own U-Net numbers come from folds that mix challenge training and test cases; they are not a leaderboard result.
  • The System 1 gate was measured on 154 commands labelled by one rater (the agent, with a rubric written before any model ran); it has been live since 29 Oct 2026 and still escalates many harmless commands to the human.
  • The 13-task model test is small; it ranks models for this use, it does not benchmark them.
  • The cmake flags in the setup are reconstructed, not copied from the build log.
  • The diagrams are generated illustrations; where they and the tables differ, the tables are right.

Where data may go

What is not here. Patient data and results on in-house cohorts stay on the machine. Only work on public datasets is published: the QC above runs on the WMH Segmentation Challenge (Utrecht, Singapore, Amsterdam), the microbleed numbers on the public VALDO 2021 training set. Checked before every push: every dataset needs an explicit release. Anything derived from in-house data inherits its class (rule), so the comparisons on the mixed pool of challenge and in-house cohorts are not shown here; for microbleeds only the VALDO part of each result is given.
